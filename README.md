# NoeEngine

**NoeEngine** is a cross-platform 2D and 3D game engine, derived from Godot Engine 4.0.

This repository contains the NoeEngine product fork. The product name, documentation, and supported distributions are being rebranded from Godot to NoeEngine. Internal Godot identifiers and compatibility interfaces may remain during the transition to avoid breaking the engine, existing projects, plugins, and builds.

## Building

The engine uses SCons. Consult the platform build instructions retained in the repository; some upstream build scripts and paths may still carry their original names until migrated and tested.
